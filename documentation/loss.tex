\section{Loss Function}

$L = (\frac{1}{c} \sum_{i=1}^{c} (y_i - \hat{y_i})^2 ) + (-\sum_{i=1}^{c} \sum_{j=1}^{n} \sum_{l=1}^{k} s_{i,j,l} ln(s_{i,j,l})) +(\sum_{i=1}^{c} \sum_{l=1}^{k} m_{i,l} ln(m_{i,l})) $


c= number of crystals

n= number of nodes per crystal

k= number of columns per assignment matrix

$m_{i,l}=\frac{1}{n}\sum_{j=1}^{n} s_{i,l,j}) $
